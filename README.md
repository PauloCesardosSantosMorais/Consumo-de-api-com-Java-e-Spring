# 🎬 Screenmatch

Projeto em Java com Spring Boot que busca informações de séries em uma API e mostra os dados no console.

Feito durante a formação Java da [Alura](https://www.alura.com.br/formacao-java).

## O que ele faz

- Busca dados de uma série em uma API externa
- Converte o JSON recebido em objetos Java
- Mostra informações como temporadas, episódios e avaliações no terminal

## Tecnologias

- Java 17
- Spring Boot
- Maven
